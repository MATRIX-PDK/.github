# MATRIX-PDK

**Memory and Advanced Transistor Research Integration Xplatform Process-Design-Kit**

MATRIX-PDK is an open research initiative from [Prof. Shimeng Yu's group](https://shimeng.ece.gatech.edu/) 
at the **Georgia Institute of Technology**, providing unified, open-source Process Design Kits (PDKs) 
for advanced memory and logic technologies.

---

## Research Areas

- 🧩 **Advanced Memory PDK** — Device-to-circuit PDKs for emerging memory technologies 
- ⚙️ **Advanced Logic PDK** — Process design kits for advanced node logic technologies (ex. Complimentary FET)
- 📐 **Technology Development & Benchmarking** — Standardized frameworks for cross-technology performance evaluation and comparison

---

## Goals

- Provide the research community with open, reproducible PDKs
- Enable fair benchmarking across memory and logic technology nodes
- Bridge device-level modeling with circuit and system-level design
